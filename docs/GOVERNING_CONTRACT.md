# Governing Contract - manasikuna Independent App

## Current decision

Manasikuna is a local-first mobile application for pilgrims under the Nusuk system and PalWakf governance during development.

## Hard constraints for this build

- No user accounts.
- No login.
- No external database.
- No hidden network submission of personal data.
- Store privacy disclosures must remain simple and accurate.
- Optional location permission is requested only by explicit user action.

## Deferred official integrations

Payments, documents upload, official applicant verification, official staff/admin workflows, and backend linkage are outside this store-ready independent build.
