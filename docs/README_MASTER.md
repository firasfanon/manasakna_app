# manasikuna Independent Mobile App

مناسكنا في هذه المرحلة تطبيق Flutter Mobile/Web محلي أولًا للحاج والمعتمر تحت إطار نسك وPalWakf، بلا تسجيل دخول وبلا قاعدة بيانات خارجية إلى حين جاهزية قاعدة بيانات نسك.

## المرجع الأساسي الجديد

يعتمد الملف التالي كمرجع تنفيذي أعلى للتطوير القادم:

`docs/MANASIKUNA_COMPREHENSIVE_SYSTEM_GUIDE.md`

أي تطوير جديد يجب أن يحدّث هذا الدليل، ثم يحدّث تقرير النسخة و`SESSION_HANDOFF.md`.

## النطاق

- خدمات الحاج والمعتمر.
- دليل التطبيق الشامل ومركز المراحل.
- دليل المناسك ومصفوفة الحج v6.
- الأسئلة حسب الزمان والمكان والجنس ونوع الحج.
- المساعد الصوتي الإرشادي الآمن.
- قائمة الجاهزية وحقيبة الحج.
- الصحة والسلامة والطوارئ والموقع عند الطلب.
- الوثائق والسكن والنقل والمجموعة بشكل محلي مؤقت.
- الشكاوى والاستبيان كمرجع محلي.
- إعدادات المظهر واللغة وحجم الخط والخدمات.
- جاهزية الربط المستقبلي مع نسك.

## خارج النطاق الحالي

أي ربط رسمي مع أنظمة تشغيلية أو بوابات دفع أو قواعد بيانات أو تحقق رسمي يجب أن يتم لاحقًا كدفعة مستقلة مع تحديثات الخصوصية والنشر.

## قاعدة المساعد

المساعد يذكّر وينبّه ويسأل ويجيب من المصفوفة والFAQ فقط، ولا يفتي ولا يهلوس، ويوجه إلى جهة الاختصاص في المسائل الحساسة.
