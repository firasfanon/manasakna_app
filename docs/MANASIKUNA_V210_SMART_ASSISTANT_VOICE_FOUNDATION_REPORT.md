# Manasikuna v2.1.0 — Smart Assistant + Voice Guidance Foundation

## الهدف
تطوير المساعد الذكي من صفحة أسئلة بسيطة إلى مساعد إرشادي آمن قادر على: الإجابة من مصفوفة الحج، التذكير، التنبيه، طرح سؤال متابعة، وتوجيه الحاج لجهة الاختصاص عند المسائل الحساسة.

## ما تم تنفيذه
- إنشاء نموذج `SmartAssistantResponse` لتصنيف ردود المساعد إلى: إجابة، تذكير، تنبيه، سؤال متابعة، وتوجيه لجهة الاختصاص.
- إنشاء نموذج `AssistantVoiceProfile` لطبقة صوت مستقبلية: تلقائي لاحقًا، صوت ذكر، صوت أنثى.
- إنشاء قائمة تذكيرات وتنبيهات تجريبية محلية مرتبطة بمراحل الحج: قبل الميقات، عرفة، مزدلفة، الجمرات، وبعد العودة.
- تحديث `SimpleHajjAssistantService` ليعمل وفق قواعد أمان واضحة:
  - لا يفتي في المسائل الخاصة.
  - لا يجيب خارج مصفوفة الحج وFAQ.
  - يوجه للجنة الشرعية أو المرشد أو الطوارئ عند الحاجة.
  - يضيف سياق المصدر والإجراء المقترح.
- تحديث صفحة المساعد بصريًا ووظيفيًا:
  - لوحة طبقة الصوت والتنبيه.
  - اختيار صوت ذكر/أنثى/تلقائي مستقبلي.
  - بطاقات تذكير وتنبيه.
  - فقاعات ردود مصنفة حسب النوع.
  - إخلاء مسؤولية أوضح.

## ما لم يتم تنفيذه عمدًا
- لم يتم إضافة حزمة TTS أو STT الآن لتجنب مشاكل الاعتماديات قبل تثبيت متطلبات الصوت قانونيًا وتقنيًا.
- لم يتم ربط الصوت ببيانات تسجيل الدخول؛ التطبيق ما زال في وضع تطوير بلا تسجيل دخول.
- لم يتم ربط التنبيهات بنظام إشعارات حقيقي أو موقع GPS؛ هذه مرحلة UI/Logic Foundation فقط.

## قواعد الاعتماد
المساعد داخل مناسكنا هو مساعد إرشادي وليس مفتيًا. يقرأ من المصفوفة، يذكّر، ينبه، يسأل ويجيب ضمن الحدود، ويوجه لجهة الاختصاص عند الحساسية الشرعية أو الصحية أو الإدارية.
