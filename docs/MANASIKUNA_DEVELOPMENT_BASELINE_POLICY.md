# سياسة baseline والتوثيق في مناسكنا

## القاعدة
كل تطوير جديد في مناسكنا يجب أن يندمج فوق أحدث baseline معتمد، ويجب أن يحدّث الملف:

`docs/MANASIKUNA_COMPREHENSIVE_SYSTEM_GUIDE.md`

قبل تسليم النسخة.

## عند إضافة صفحة جديدة
يجب تحديث:
- الراوتر.
- enum الخدمة.
- قائمة الخدمات إن كانت ظاهرة للمستخدم.
- تقرير النسخة.
- Session Handoff.
- الدليل الشامل.

## عند إضافة منطق شرعي أو FAQ
يجب توثيق:
- مصدره داخل مصفوفة الحج أو FAQ.
- مستوى الحساسية.
- هل يحتاج اعتماد اللجنة الشرعية.
- صياغة الإحالة عند عدم الجزم.

## عند إضافة ربط سيرفر لاحقًا
يجب توثيق:
- الجداول أو RPC أو API.
- الصلاحيات والخصوصية.
- أثره على وضع الضيف ووضع المستخدم المسجل.
