# MANASIKUNA v2.0.1 — Journey Margin Crash Fix

## السبب
ظهرت شاشة حمراء عند الضغط على زر "رحلتي" بسبب استخدام هامش أفقي سالب داخل `Container`:

```dart
margin: EdgeInsets.symmetric(horizontal: -18)
```

وهذا غير مسموح في Flutter لأن `EdgeInsets` المستخدم في `margin` يجب أن يكون غير سالب.

## الإصلاح
تم إصلاح صفحة الرحلة بشكل موضعي دون إعادة هندسة الواجهة:

- إزالة الهامش السالب من رأس صفحة `رحلتي`.
- جعل `ListView` بلا حشوة أفقية عامة حتى يبقى الرأس ممتدًا بصريًا.
- إضافة حشوة أفقية للعناصر الداخلية فقط: بطاقة المرحلة الحالية، عنوان المراحل، الـ timeline، والتنبيه.
- الحفاظ على النمط البصري المعتمد من الصورة المرجعية.
