# Nusuk Admin Bridge

هذا المجلد placeholder لمسار الربط مع منصة PalWakf.

المطلوب عند وصول ملفات المنصة:

- إضافة `SystemKey.nusuk`.
- إضافة صلاحيات `PermissionKey.manageNusuk...`.
- إضافة Dashboard card لنظام نسك.
- ربط routes الإدارية داخل SystemShell.
- بناء صفحات إدارة المواسم والبرامج والشركات والطلبات.
