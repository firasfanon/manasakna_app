# Privacy Policy - manasikuna

manasikuna runs locally on the user's device in this version and does not require account creation or login.

## Data

The app does not collect personal data or send it to external servers in this version.

## Local settings

The app stores preferences locally on the device, such as language, theme mode, text size, and preferred Hajj/Umrah path. These settings are not sent to any server.

## Location

The app may request location permission only when the user opens the "Current Location" feature. The location is displayed on the device so the user can manually share coordinates if needed. The app does not send location data to an external server.

## Accounts

The app has no user accounts, so account deletion is not applicable.

## Tracking and ads

The app does not use ads, tracking tools, or external analytics in this version.
