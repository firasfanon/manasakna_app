# MANASIKUNA v2.6.0 — Operational Companion Big Batch

تم دمج دفعة كبيرة من الصفحات الداخلية داخل baseline الكامل، وتشمل: رفيق اليوم، نوع الحج والنية، المواقيت الشرعية، الدليل المكاني، والمكتبة دون إنترنت.

## مبدأ الدفعة
- لا تسجيل دخول في مرحلة التطوير.
- لا ربط سيرفر بعد.
- كل المحتوى محلي وتجريبي/إرشادي.
- لا فتوى نهائية قبل اعتماد اللجنة الشرعية.
- لا رجوع لأي legacy أو ASP.

## مسار الاختبار المحلي
```bash
flutter clean
flutter pub get
flutter test
flutter run -d chrome
```
